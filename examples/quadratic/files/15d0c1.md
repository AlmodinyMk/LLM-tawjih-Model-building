=== human ===
الصورة القياسية: a·x² + b·x + c = 0 حيث a ≠ 0. المميز Δ = b² − 4ac. إذا Δ>0 فجذران حقيقيان مختلفان، وإذا Δ=0 فجذر مكرر، وإذا Δ<0 فجذران مركبان مترافقان. الجذران: x = (−b ± √Δ) / 2a.
