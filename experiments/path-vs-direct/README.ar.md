# المسار أم السؤال المباشر: قياس تجريه بنفسك

[English](README.md)

يدّعي توجيه أن المسار المراجَع يعطي إجابات أفضل من سؤال النموذج السؤالَ نفسه
مباشرة. يقيس هذا المجلد ذلك الادعاء على مشروع المثال (المعادلات التربيعية)
بنماذجك أنت عبر Ollama، ولا يحتاج إلا بايثون وOllama.

```
ollama pull qwen2.5:3b
python experiments/path-vs-direct/run.py --models qwen2.5:3b
```

وتجربة أوسع بعدة نماذج (واحداً بعد آخر):

```
ollama pull qwen2.5:1.5b
ollama pull llama3.2:3b
python experiments/path-vs-direct/run.py --models qwen2.5:1.5b,qwen2.5:3b,llama3.2:3b \
    --cases 60 --repeat 3
```

يطبع البرنامج عدد استدعاءات النموذج قبل أن يبدأ. النموذج الصغير على بطاقة رسوميات
يجيب في ثوانٍ، وعلى المعالج قد تأخذ التجربة ساعة أو أكثر. و`--cases 20 --repeat 1`
نظرة أولى سريعة.

## ما الذي يُقارَن

تُسأل كل معادلة بثلاث طرق، كلٌّ `--repeat` مرة:

| الطريقة | ما يُعطى للنموذج |
|---|---|
| `path` | مسار المثال: يحوّل النموذج المعادلة إلى a وb وc، ثم تحلّها بايثون وتتحقق من الجذرين مرتين، ثم يشرح النموذج النتيجة المحسوبة |
| `direct` | السؤال، وسطر واحد يقول كيف يُكتب الجواب (`x = القيمة`)، حتى تُقاس الطريقتان بالاختبار نفسه |
| `steps` | مثل السابق، مع طلب الحل خطوة بخطوة أولاً |

الحالات هي معادلات المثال العشرون، ثم معادلات مولّدة (البذرة 7):
- جذور ومعاملات رئيسية أكبر؛
- حدود رئيسية سالبة؛
- جذور مكررة؛
- حدود على طرفي المعادلة.

نصفها بالعربية ونصفها بالإنجليزية. وتتحقق الاختبارات أن كل معادلة مولّدة لها
الجذور التي تُقاس عليها.

## ما تحصل عليه

`results/summary.md` فيه جدول لكل نموذج:
- نسبة الإجابات الصحيحة مع مجال ثقة 95%؛
- الحالات الصحيحة في كل مرة؛
- الثواني والرموز لكل حالة؛
- الفرق بين المسار وكل طريقة مباشرة، مع مجاله؛
- الحالات التي أصابها أحدهما وحده، واختبار McNemar الدقيق؛
- المقارنات نفسها لكل مجموعة (المثال أو المولّدة، العربية أو الإنجليزية).

`results/results.json` فيه الباقي:
- الإعدادات؛
- الجهاز، وإصدار توجيه، وبصمة كل نموذج؛
- كل حالة وكل إجابة.

وسجلات كل تشغيل في `results/work/`.

أرسل `summary.md` و`results.json`، أو افتح بهما بلاغاً. وأياً كانت الأرقام، تدخل
README والورقة.

## ما يُثبته هذا وما لا يُثبته

- **المسار يحسب.** حسابه تقوم به بايثون، فالمقارنة هي «نموذج مع خطوات كود
  مراجَعة» مقابل «نموذج وحده». ونتيجتها عن تقسيم المهمة إلى خطوات بعضها كود، ولا
  تقيس المعرفة المحفوظة في الملفات (الوجهين البشري والعلمي). ذلك يحتاج مثالاً
  آخر تعتمد إجاباته على ما تعرفه الملفات لا على الحساب.
- **الاختبار نمط.** تُحسب الحالة صحيحة حين يقول الجواب `x = r` لكل جذر. فالجواب
  الصحيح المكتوب بصيغة أخرى (`x ∈ {2, 3}`) يُحسب خطأ. ولهذا تطلب `direct` و`steps`
  هذه الصيغة، إنصافاً. اقرأ بعض الإخفاقات في `results.json` قبل أن تثق بفرق صغير.
- **العينة صغيرة.** مع 60 حالة، فرق نقاط قليلة يقع ضمن الصدفة: انظر إلى المجالات
  وقيمة p، لا إلى النسب وحدها.
- **المعادلات سهلة.** النماذج القوية قد تحلّها كلها بالطريقتين. والسؤال أهم ما
  يكون للنماذج المحلية الصغيرة، حيث يُتوقع أن يكون الفرق أكبر.
